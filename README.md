Dependency-free static portfolio foundation.

## Local preview

```bash
/Users/cellphones/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node --test tests/portfolio.test.mjs
/Users/cellphones/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

Open `http://127.0.0.1:4173` after starting the server.

## Updating portfolio content

- Replace `assets/images/portrait-placeholder.svg` with the supplied portrait only when it is approved for publication; retain appropriate alternative text when it conveys useful content.
- Update `assets/js/case-studies.js` only with approved, source-backed evidence. Keep each record visibly labelled as a demo until supporting materials are available.
- Update phone, email, and LinkedIn values consistently in `index.html` when contact details change.
- The CV PDF is not a public asset and must not be copied into this site.
